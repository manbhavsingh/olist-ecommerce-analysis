# Power BI dashboard
Built in Power BI Desktop from the 4 CSVs in `data/powerbi/` (generated by the notebook).
Model: `orders[order_id]` -> `order_items[order_id]` (one-to-many). Cohort retention and seller summary tables are standalone because they are pre-aggregated exports. Their visuals will not automatically respond to filters from `orders` unless the visual is rebuilt from the fact tables.
Reconciliation targets: Total Revenue R$13,220,249 | Orders 96,470 | Late % 8.11%.

Pages: 1 Executive Summary | 2 Sales & Customers | 3 Logistics & Experience.
Status: the four data tables and base page layouts are ready; the PBIX itself is not included. The DAX list below now includes all KPI measures shown in the previews. `preview_page*.png` are Python-rendered previews of the layout, NOT Power BI screenshots.
After building the report in Power BI Desktop, add `olist_dashboard.pbix` and real screenshots to this folder.

## DAX measures
```dax
Total Revenue = SUM(orders[revenue])
Orders = COUNTROWS(orders)
AOV = DIVIDE([Total Revenue],[Orders])
Late % = AVERAGE(orders[late_flag])
Late Orders = SUM(orders[late_flag])
Avg Review = AVERAGE(orders[review_score])
Median Delivery Days = MEDIAN(orders[delivery_days])
Item Revenue = SUM(order_items[price])
Customers = DISTINCTCOUNT(orders[customer_unique_id])
Repeat Customers =
VAR CustomerOrders =
    ADDCOLUMNS(
        VALUES(orders[customer_unique_id]),
        "__OrderCount", CALCULATE([Orders])
    )
RETURN
    COUNTROWS(FILTER(CustomerOrders, [__OrderCount] > 1))
Repeat Rate = DIVIDE([Repeat Customers], [Customers])
Top-10% Customer Revenue Share =
VAR CustomerSpend =
    ADDCOLUMNS(
        VALUES(orders[customer_unique_id]),
        "__Spend", CALCULATE([Total Revenue])
    )
VAR TopCustomers =
    TOPN(
        ROUNDUP([Customers] * 0.10, 0),
        CustomerSpend,
        [__Spend], DESC
    )
RETURN
    DIVIDE(SUMX(TopCustomers, [__Spend]), [Total Revenue])
Returning Order Share =
DIVIDE(CALCULATE([Orders],orders[customer_type_first]="Returning"),[Orders])
```

## Seller metric definition
Seller lateness and seller average review are calculated at the **seller-order grain** before seller aggregation. This prevents multi-item orders from receiving extra weight. There are 425 sellers with 50+ delivered orders; 35 exceed 15% late and the seller-level correlation between late % and average review is about -0.50.

## Filter/interactivity note
The supplied four-table design is sufficient for the three static dashboard pages. Because `cohort_retention` and `sellers_50plus` are standalone summaries, page filters from `orders` will not propagate into those tables. For a fully interactive report, rebuild those visuals from `orders`/`order_items` with measures, or add an appropriate dimensional model.
